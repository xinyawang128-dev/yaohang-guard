# 演示视频脚本

建议 4 分钟。使用最终工程的 00_打开演示和结果页面.bat，选择“已保存的 MCP 结果”展示 AGH 调用后生成的曲线；同时录制 AGH 的原始工具痕迹。真实 AGH 接入后录制；若先录制离线版，开头和界面均保留离线标识，不将其作为最终 AGH 证据。

| 时间 | 画面 | 讲述要点 |
| --- | --- | --- |
| 0:00–0:30 | 项目名称与配送任务 | 介绍温度约束、航程与能量约束及其合成参数来源；目标是交付合规的仿真任务，并能处理途中异常。 |
| 0:30–1:15 | 真实 Agnes 会话调用工具 | 显示 AGH 环境、实际 Agnes 模型名称、create_task 与 plan_candidates；比较同包装的最短路和安全候选。 |
| 1:15–2:15 | 分段执行和封闭 R-D | 当前温度、电量和时间连续变化。模型收到封闭反馈后，从 R 改为 R-E-D，验证后继续。 |
| 2:15–3:00 | 温度曲线和验证 JSON | 展示交付节点、上限、能耗、保留电量，以及工具产生的校验结果；解释角点和合成扰动验证范围。 |
| 3:00–3:35 | 失败测试 | 展示低电量拒绝起飞、传感器失效停止，说明异常处理不会虚报成功。 |
| 3:35–4:00 | 代码和下一步验证 | 普通电脑可运行；进一步用水瓶、保温箱和温度记录器测热时间常数。说明目前使用合成数据，真实飞行与药品质量尚未验证。 |

录屏前检查：浏览器页面正常；模型与工具记录能看清；关闭密钥、个人信息和通知；导出的证据可读；公开视频链接无需登录；视频内没有虚假的真实实验或获奖说法。

本地仿真测试可用于解释工程模块：常规交付约 12.94 min、124.39 Wh、末温 6.34°C；航路封闭后约 16.44 min、158.07 Wh、末温 6.66°C。真实 Agnes 会话若选用不同可行航路，录制时引用该会话实际结果。

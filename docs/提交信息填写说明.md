# 提交信息填写说明

双击 07_填写提交信息.bat，在记事本中修改 submission_info.json，保存后再运行 06_整理比赛数据.bat。JSON 使用英文双引号；每项之间保留逗号，最后一项后不要额外加逗号。

| 字段 | 填什么 |
|---|---|
| group | 本科生组或硕博组，以实际报名为准 |
| registration_id | 赛事参赛编号 |
| team_name / leader_name / school | 实际队名、队长、学校 |
| video.url | 已上传的 3–5 分钟演示视频链接；评委无需登录个人账号即可观看 |
| video.duration_seconds | 实际秒数，数字，例如 240；替换原来的 null |
| video.backup_url / password | 可选备用链接、所需访问口令 |
| public_posts | 至少一条已公开作品内容的平台、链接、发布日期（YYYY-MM-DD）、截图路径 |
| members | 每位成员姓名、实际分工、本人声明文件路径；多名成员增加对象 |
| models_used | 实际模型名称、版本、使用阶段、调用方式；与 AGH 记录一致 |
| development_ai_disclosure | 实际使用 ChatGPT/Codex 等辅助工具的范围及成员审核、修改工作 |

文件路径相对于本工程，例如 `materials/成员声明/张同学.pdf`、`materials/公开内容截图/作品介绍.png`。先把实际文件放进去，再填写相对路径。视频建议使用链接，以保持 ZIP 不超过 200 MB。成员模板不能代替真实签署或官方表单。

模型版本可先查看 submission/比赛测试数据.csv 的“实际模型”列，并核对 AGH 原始痕迹。不要仅凭 UI 名称填造调用记录。组别与编号决定正式整理包名称：组别-参赛编号-队伍名称-队长姓名.zip。

自动检查会列出缺少字段和文件，但不能验证链接是否公开可访问、声明是否真实或是否符合最终赛事审核。因此最终提交前人工打开视频和公开链接，检查成员声明与原始 AGH 会话。

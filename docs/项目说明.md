# 药航守护

项目创意：让 Agnes 在 AGH 中调用冷链与航程计算工具，为药品配送选择包装和航线，遇到途中异常后根据实际仿真反馈重新规划或停止仿真任务并转人工处理。

组别按团队实际学历选择本科生组或硕博组。参考方向为 Agent/Harness 工程，结合数字孪生、生命健康和航空航天应用；参考方向不是独立赛道。

## 具体问题与结果

只考虑最短航程的方案可能满足时间要求，却无法在热暴露和参数不确定性下满足箱内温度要求。本项目把示例温度窗口、交付时间、航程能耗和预留电量共同作为约束，先计算，再执行一段，再根据反馈调整。

默认温度窗口为 2–8°C，初温 5°C，环境 32°C，逆风 1 m/s，电池 320 Wh，预留 35 Wh，时限 25 分钟。地图为六个合成节点、八条航路，两种示例包装；这些参数不是对特定药品或无人机的认证参数。

## AGH 与模型承担的工作

AGH 承载实际 Agnes 会话、MCP 工具发现、工具调用、执行反馈、审批和痕迹记录。模型负责理解目标、读取候选计划、解释选择、调用下一段、收到封路或观测失败反馈后重新决策。Python 工具负责独立计算约束和状态，拒绝不合法执行，保存实际数值。

闭环通过八个工具完成：create_task → plan_candidates → simulate_plan → execute_step；事件由 inject_event 触发；无解或缺少温度观测时 abort_task；结束后 verify_delivery 与 export_evidence 留存任务证据。execute_step 一次只前进一条边，当前位置、时间、能耗和温度持久化到 SQLite，出发后不能改包装。

每次 plan_candidates 枚举当前节点可到达 D 的路线，评估标准／加强包装并排序。评分采用最坏时间 + 0.025×最坏能耗 + 0.7×包装质量，只在满足全部约束的方案中选择。模型可以选不同的可行候选，实际数值以工具与原始会话为准。

## 可解释的简化模型

- 地速为 12−逆风，单位 m/s；每段时间为距离×1000／地速／60，单位分钟。
- 功率为 430+90×总载荷质量+12×逆风²，单位 W；按时间积分计算能耗 Wh。
- 箱内温度采用一阶换热关系：T新 = T等效环境 + (T旧−T等效环境)×exp(−Δt/τ)。标准／加强包装的示例 τ 分别为 110／280 分钟。部分航段用合成等效环境温升表示热暴露。
- 环境 ±2°C、逆风增加 0–2 m/s、热时间常数 ±15% 的八个角点全部通过才算稳健可行。
- 100 次固定种子合成扰动只评估初始静态方案，不能解释为真实可靠性，也不能当作自适应重规划的统计结果。

模型没有包含真实飞行姿态、空域授权、药品降解动力学或包装实验标定；结果限定为工程仿真。用户端输入可用于离线探索，比赛固定用例不能放宽约束。

## 验证设计

| 用例 | 触发条件 | 应观察的结果 |
|---|---|---|
| 正常 | 默认条件 | 选择稳健方案，完成可验证配送 |
| 封路 | A→B→R 后封闭 R-D | 保留状态和包装，从 R 重新规划，避开封路继续配送 |
| 时间边界 | 时限 12 min | 没有稳健方案，拒绝起飞，A 节点能耗为 0 |
| 传感器故障 | 完成第一段后注入故障 | 不再接受温度交付验证，后续执行被拒绝并停止仿真任务并转人工处理 |
| 逆风（附加） | 第一段后逆风增至 6 m/s | 根据剩余可行性决定中止 |
| 低电量（附加） | 电池 55 Wh | 预留约束下拒绝起飞 |
| 高温（附加） | 环境 38°C | 重新选择符合温度和航程约束的方案 |

数据包含实际航线、包装、分段轨迹、温度、电量、时间、工具参数／结果、代码摘要和对应 AGH 会话。开发环境测试只证明本机代码行为；比赛记录必须在参赛团队的 AGH 中实际执行产生。影片和说明应使用本队导出的实际结果。

## 本机验证与工程边界

修订版新增航时、恒定功率能耗、一阶换热闭式解、载荷增量及电量等号边界的独立计算检查。默认四个核心用例和三项附加用例均可在本机复现。实际结果和基线对照见工程验证报告及本机检查目录。

当前“中止”表示暂停合成仿真并保留当前位置和资源，等待人工处理；没有实现真实飞行返航或降落。所有参数为合成示例，2–8°C 窗口不代表所有药品统一要求。地图无真实设备同步，属于配送过程仿真原型。
